🎨 Artist Portfolio Website

A modern and responsive Artist Portfolio Website built using HTML, CSS, and Flask.
This project allows artists to showcase their artwork, connect with clients, and build a personal brand online.

🚀 Features
🖼️ Beautiful Gallery to showcase artwork
👤 About section for artist profile
🌐 Responsive design (works on mobile & desktop)
🎨 Clean and modern UI

🛠️ Tech Stack
Frontend: HTML, CSS, JavaScript
Backend: Flask (Python)
